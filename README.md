# 📁 FileForge – Dynamic File Organizer

## 🌟 About the Project

**FileForge** is a Python-based desktop application that automatically organizes files into separate folders according to their file extensions. It provides a simple graphical interface to make file management easier and faster.

## ✨ Features

- 📂 **Folder Selection** – Choose any folder to organize.
- 🗂️ **Automatic Sorting** – Categorizes files by extension.
- 👀 **Preview Mode** – Review planned changes before organizing.
- 🛡️ **Duplicate Protection** – Prevents overwriting existing files.
- 📊 **JSON Report** – Generates a report of file organization.
- 🖥️ **User-Friendly GUI** – Simple interface built with Tkinter.

## 🛠️ Tech Stack

| Technology  | Purpose                   |
| ----------- | ------------------------- |
| 🐍 Python   | Core programming language |
| 🖥️ Tkinter | Graphical user interface  |
| 📁 pathlib  | File and folder paths     |
| 🔄 shutil   | File operations           |
| 📄 JSON     | Organization reports      |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/crsrikanth1306-dev/FileForge-Dynamic-File-Organizer.git
```

### 2. Open the project folder

```bash
cd FileForge-Dynamic-File-Organizer
```

### 3. Run the application

```bash
python fileforge.py
```
